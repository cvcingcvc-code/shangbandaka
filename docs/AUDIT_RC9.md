## 推送、网络和权限

- 静态审计未发现消息推送 SDK、广告/遥测 SDK、自建坐标上传接口、远程控制入口或开机自启。主要依赖是 AndroidX core/appcompat。独立读取工具没有 INTERNET 权限，坐标只在屏幕内存显示。
- 本应用通知是用户开始模拟后的低优先级前台服务通知；定位服务不导出，停止后移除通知。这是运行状态提示，不能作为定位成功证据。
- 必要联网包括 Nominatim 地点搜索、OpenStreetMap 瓦片。服务方会收到查询词、网络 IP 或所浏览地图区域。用户点击地图归属链接时，可打开系统浏览器。不能把本应用描述为完全离线或不向任何第三方提供地点信息。
- 已将 allowBackup 声明改为 false，避免按普通应用自动备份配置清理标记；没有卸载应用或清除用户数据。
- 旧高德辅助类未被当前主流程调用；未据此新增搜索接口。公共 Nominatim 的全应用总限流、无需更新即可切换服务等公开规模使用条件尚未完成，不能承诺无限制的免费公共搜索服务。

## 发现并修复

1. 原搜索日志主动输出查询词、完整 URL、响应片段及首条结果坐标；服务主动输出模拟目标坐标。已移除这些记录，搜索保留请求编号、HTTP 状态、结果数量及异常种类，避免 URL 随异常堆栈进入日志。
2. 原地图 WebView 允许外站导航，同时存在原生选点桥。现只允许本地 map.html 在桥所在页面加载；有用户手势的 HTTPS 主页面链接交系统浏览器，其余不可信导航阻止；普通文件、content 及文件跨域访问关闭。地图瓦片和本地 assets 保留。
3. 首次清理失败、退出时重试成功后，旧界面仍可能保持 CLEANUP_FAILED。现按最终清理结果更新：用户停止进入等待正常定位；运行异常保留 FAILED，先前错误仍可追踪。没有新增“自动确认正常定位”或第三方检测绕过。
